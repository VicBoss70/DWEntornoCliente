Ejercicio 3

Coerción y comparaciones

JavaScript puede convertir tipos automáticamente según el operador. Se comparan los mismos valores con igualdad flexible (==) y estricta (===).

"5" - 2;          // espero 3
"5" + 2;          // espero "52"
10 + false;       // espero 10
"10" - true;      // espero 9
"hola" + 3;       // espero "hola3" (ejemplo propio)
"6" / "2";        // espero 3 (ejemplo propio)
5 == "5";         // espero true
5 === "5";        // espero false
0 == false;       // espero true
0 === false;      // espero false
null == undefined;  // espero true
null === undefined; // espero false
